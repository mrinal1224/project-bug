# HelpDesk Pro — React Debugging Interview

## Setup
```bash
npm install
npm run dev
```

## Candidate task

You inherited a small support operations dashboard.

The product should let agents:
- search and filter customer tickets
- change ticket status
- switch assignees and sort the queue
- open a ticket and read the conversation
- send a reply
- view customer context
- toggle dark mode

The current implementation contains several intentional production-style bugs.

### Interview expectations

Reproduce the issues before changing code. Explain the root cause, make the smallest safe fix, and avoid rewriting the application.

Focus on React state, derived state, async behaviour, component lifecycle, and UI consistency.
